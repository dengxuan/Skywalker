# SKY9001: Service class must be partial

| Item | Value |
|---|---|
| Severity | Error |
| Introduced in | 2.0.0 |
| Category | Skywalker.SourceGenerators |

## Cause

A Skywalker source generator found a class marked for generator processing, but the class is not declared `partial`.

Skywalker generators may emit companion declarations for user classes. C# can only merge the generated declaration with the user declaration when both declarations are `partial`.

## Incorrect Example

```csharp
using Skywalker.DependencyInjection;

[ApplicationService]
public sealed class OrderService
{
}
```

## Correct Example

```csharp
using Skywalker.DependencyInjection;

[ApplicationService]
public sealed partial class OrderService
{
}
```

## Fix

Add the `partial` modifier to the class reported by the diagnostic.

If the class is `public`, `internal`, `sealed`, `abstract`, generic, nested, or has a primary constructor, keep the existing modifiers and add `partial` alongside them.
