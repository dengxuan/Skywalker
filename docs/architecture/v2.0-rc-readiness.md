## Goal

Track the remaining gates before `v2.0.0-rc.1` can be tagged. RC readiness means the source-generator rewrite tracks are complete enough to stop adding release-scope features and switch to stabilization-only work.

## Current Release Shape

- EF Repository registration uses generated metadata first and keeps reflection fallback only for non-AOT compatibility.
- DynamicProxy uses source-generated static proxies and no longer depends on Castle.Core at runtime.
- DI auto-registration emits generated registrar metadata consumed by `AddSkywalker()`.
- The sample matrix covers EF repository, DynamicProxy, DI auto-registration, NativeAOT, and migration canaries.
- Messaging/Transport has been spun out to Vertex and is documented as a v2.0 breaking change.
